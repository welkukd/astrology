# Astrology Assistant - Development Setup

## Prerequisites
- Docker & Docker Compose
- Supabase account (free tier)
- Google AI Studio account (for Gemini API - free tier)

## Quick Start

### 1. Set up Supabase
1. Create a new project at https://supabase.com
2. Go to Settings > API and copy:
   - Project URL
   - Anon (public) key
   - Service role key (keep secret!)
3. Go to Settings > Database and copy the JWT Secret
4. Run the SQL from `supabase/schema.sql` in the Supabase SQL Editor

### 2. Get API Keys
- **Gemini API**: https://aistudio.google.com/apikey (free tier: 15 RPM, 1M tokens/min)
- **Groq API** (alternative): https://console.groq.com/keys (free tier: Llama 3.1 70B)

### 3. Configure Environment
```bash
# Backend
cp apps/api/.env.example apps/api/.env
# Edit apps/api/.env with your Supabase credentials and AI API key

# Frontend
cp apps/web/.env.example apps/web/.env.local
# Edit apps/web/.env.local with your Supabase credentials
```

### 4. Run with Docker
```bash
docker-compose up --build
```

- Frontend: http://localhost:3000
- API Docs: http://localhost:8000/docs
- API Health: http://localhost:8000/health

### 5. Run Locally (without Docker)

**Backend:**
```bash
cd apps/api
python -m venv venv
source venv/bin/activate  # or venv\Scripts\activate on Windows
pip install -r requirements.txt
cp .env.example .env
# Edit .env
uvicorn app.main:app --reload --port 8000
```

**Frontend:**
```bash
cd apps/web
npm install
cp .env.example .env.local
# Edit .env.local
npm run dev
```

## API Endpoints

| Method | Endpoint | Description |
|--------|----------|-------------|
| POST | /api/v1/natal | Calculate natal chart |
| GET | /api/v1/charts | List user's charts |
| GET | /api/v1/charts/{id} | Get chart details |
| DELETE | /api/v1/charts/{id} | Delete chart (GDPR) |
| POST | /api/v1/charts/{id}/export | Export chart as JSON |
| POST | /api/v1/interpret | Get AI interpretation |

## Deployment

### Vercel (Frontend) + Railway/Render (Backend)

1. Push to GitHub
2. Connect Vercel to repo, set root to `apps/web`
3. Add environment variables in Vercel dashboard
4. Deploy backend to Railway/Render:
   - Build: `pip install -r requirements.txt`
   - Start: `uvicorn app.main:app --host 0.0.0.0 --port $PORT`
   - Add environment variables
5. Update `NEXT_PUBLIC_API_URL` in Vercel to production backend URL
